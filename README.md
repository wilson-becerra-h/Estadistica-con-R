# 📊 Análisis Estadístico con R

Bienvenido a este repositorio. Aquí se reúnen scripts, reportes dinámicos y recursos prácticos para el **análisis estadístico descriptivo e inferencial** utilizando el lenguaje R y el entorno RStudio.

---

## 🛠️ Tecnologías y Librerías Utilizadas

El análisis está implementado en R y utiliza los principales paquetes del ecosistema para ciencia de datos y estadística:

* **Manipulación y Limpieza de Datos:** `tidyverse` (`dplyr`, `tidyr`, `stringr`)
* **Análisis Estadístico:** `stats`, `janitor`
* **Visualización de Datos:** `ggplot2`
* **Reportes Dinámicos:** `rmarkdown` / `knitr`
